# v0.7.1 WP1.3.1 Resume Fidelity Correction Eval Plan

## E0 Contract

- layout parser、field span、list auto-complete 和 reparse 版本语义与契约一致。

## E1 Unit

- 无标签个人头部；
- layout PDF 提取与质量回退；
- normalized text 到原文 offset 映射；
- 非空列表自动完成、空列表确认。

## E2 Integration / CLI

- `--reparse` 创建新 Draft，旧 Snapshot 保持可读；
- Source 摘要命中当前记录而非页首；
- 非空列表不产生 section-complete request；
- reparse 前 Candidate Claim 数量作为新 run baseline。

## E3 Real PDF

对同一真实 PDF 执行 `resume import --reparse`，核对个人信息、教育归属、项目、荣誉、技能、
“至今”、SourceRef span 和 PII 日志门禁。人工确认前不发布新 Snapshot。

## Exit

全量 pytest、compileall、git diff --check 通过；真实 Draft 字段对齐后进入用户确认。
