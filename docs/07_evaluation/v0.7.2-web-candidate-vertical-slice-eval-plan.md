# v0.7.2 Web Candidate Vertical Slice Eval Plan

状态：Offline Executed；Live/Human Pending

## E0 Contract

- JSON envelope 和 HTTP 错误映射。
- 固定 local owner，拒绝跨 Session/owner 对象。
- 上传扩展名、MIME、大小、临时文件清理。
- Candidate/Resume response idempotency。

## E1 API Integration

- 创建 Session。
- 匿名 PDF → Resume interrupted review。
- review view 含 section/value/source pages/excerpts。
- 完成全部 review → confirmed ResumeEvidence。
- Candidate build → completed 或 interrupted，且 Snapshot/Claim provenance 不变。
- Candidate answer/upload → 相同 thread 恢复并生成 successor Snapshot。

## E2 Frontend

- production build。
- 360px、768px、1440px 响应式布局无水平溢出。
- 键盘可访问的 upload、review、question 和 retry 操作。
- loading、empty、interrupted、completed、cancelled、failed 状态有明确反馈。
- 未开放模块不可操作且不展示伪业务结果。

## E3 Regression

- 验证 `src/campus_job_agent` 现有业务文件无本工作包修改。
