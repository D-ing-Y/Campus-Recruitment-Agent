## 2. Offline cases

- Brave query 始终绑定 Nowcoder domain；URL/path/final URL 越界被拒绝。
- Brave/Crawl4AI/MediaCrawler 均 raw-before-parse；snippet 不能生成 Segment。
- robots、429、login、challenge、redirect、DOM drift、missing dependency 使用正确 failure mapping。
- 一个批量调用只创建一个 Crawl4AI browser session，默认 concurrency=2。
- canonical URL、post ID、body hash、5-char shingle 和 semantic merge 均有正反 fixture。
- 运行级分用途校准产生来源排序，代码稳定映射 70/30；来源阻断映射 100/0。
- LLM 提议未知公司、岗位族、域名、来源、预算或不存在 segment ID 时 receipt rejected。
- 每用途少于 3 簇永不 sufficient；三轮或预算耗尽后显式 partial。
- checkpoint 不保存 detail body，resume/idempotent replay 不重复 Artifact、cluster 或 receipt。

## 3. Baseline comparison

固定三级主备级联作为 baseline，自适应策略统计：

- `unique_cluster_per_detail`
- `accepted_segment_per_detail`
- `duplicate_detail_rate`
- `scope_accept_rate`
- `search_calls/detail_calls/llm_calls`
- `latency_ms` 与 Brave request cost

自适应策略必须保持所有安全门禁，并至少在一个 duplicate-heavy fixture 上减少无效详情抓取；否则保留
固定 baseline，不宣称质量收益。

## 4. Opt-in live

1. Brave：简单 `site:nowcoder.com 公司 岗位 面经` 返回至少一个 allowlisted URL，归档 search Raw。
2. Crawl4AI：抓取一个 robots 允许的公开详情，归档 rendered Raw，得到唯一主帖 Fragment 和可定位 quote。
3. MediaCrawler：通过正常外部会话完成 search/detail，或保留真实 blocked 状态。
4. 完整 L2：面经、风评各 3 个独立内容簇；任何一项不足时 WP3.2 live 状态为 partial。

默认 CI 不运行 live，不提交完整社区正文、Cookie、token、个人账号或本地输出路径。
