## 4. 测试覆盖

- schema 与迁移：CareerIntent structured constraint、legacy string 待确认迁移、v0.3 Gap 只读迁移。
- qualification：equals/in/contains/gte/lte/range 真值表、双方 Claim 门禁和 overall status。
- capability：exact/显式 transfer/unmapped、等级比较、证据不足与 unknown 边界。
- coverage：core/bonus 权重、分子、分母、uncertain、excluded 和 denominator=0。
- preference：hard/negotiable、location/work mode/salary unit 与未知字段。
- comparison：failed 保留、稳定字典序、tier 和输入顺序稳定性。
- persistence：owner read boundary、不可变幂等复用、stale lifecycle、原子 decision batch。
- Graph：v0.4 candidate + v0.5 role fixture 到 comparison review interrupt；
  select/defer/reject、candidate revision、intent rematch/research、role refresh、预算停止。
- recovery：SQLite checkpoint 跨 Graph 实例恢复与重复 response 零重复写入。
- LLM：fact/citation/action/数字/概率声明 mutation 拒绝，provider/validator 失败使用确定性模板。

## 6. 已知限制

- v0.6 只输出跨域 directive，不直接调用 v0.4/v0.5；Parent Graph 仍属于 v1.0。
- v0.5 `SearchScope` 每个 run 仍只支持一个 canonical role family；多方向需独立 run。
- legacy snapshot 若既没有 owner 字段也没有可追溯 Claim/Artifact，只能在迁移后参与严格 owner 校验。
- DeepSeek smoke 使用合成事实，只验证 structured explanation 边界，不代表开放世界岗位判断质量。

以上均为已声明的版本边界，没有剩余必需验收项。
