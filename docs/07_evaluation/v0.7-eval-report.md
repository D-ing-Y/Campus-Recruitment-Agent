## 4. 测试覆盖

- Preparation schema/repository：canonical hash、owner、immutable reuse、stale/supersede 和事务回执。
- Policy/scheduler：P0-P4、stable order、必要申请材料、optional bonus、DAG/cycle、split、timezone、
  unavailable date、daily/weekly capacity、deadline 与相同输入 schedule hash。
- Preparation Graph：selected target→plan→review→accept、constraint revision、blocked/partial、
  SQLite restart、duplicate response 和预算终止。
- Feedback：raw Artifact/Fragment 优先、dedup、raw-write failure、observation/diagnosis/outcome、
  source authority、scope、rejection guard、task-progress-only 和 role-family single-event guard。
- Feedback Graph/saga：attribution interrupt、Claim trace、Impact/Directive、后继 snapshot refs、
  SQLite restart、重复 event/response，以及 Candidate snapshot→rematch→replan→supersede。
- LLM 边界：非法 priority/ref/URL/因果 mutation 拒绝；一次 retry 后使用确定性 fallback。
