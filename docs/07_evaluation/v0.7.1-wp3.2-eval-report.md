## 1. 结论

Brave Search + Crawl4AI + MediaCrawler REST 的 WP3.2 代码、契约、离线 Graph 和安装态 CLI 已通过。
这只证明受控查询、raw-before-parse、详情 allowlist、批量抓取、正文唯一性、分用途分类、三层去重、
70/30 分配和三簇门槛闭合；不等于真实社区内容 L2 accepted。

真实 smoke 中，本地 Brave credential ref 存在且未泄露，但官方接口返回
`authentication_required`；Crawl4AI 0.9.2 与 Chromium 已就绪，显式公开牛客详情仍返回登录墙并被
归类为 `authentication_required`；MediaCrawler doctor 为 `adapter_required`。因此本次 live 状态只能
是 partial/blocked，没有用 fixture、搜索摘要或模型常识补齐。
