## 2. 测试场景

- Profile init/open/status/stop 的成功、幂等、路径越界、符号链接、端口冲突和 PID 身份不匹配。
- 牛客 collect 只接受 Brave CredentialRef，detail 只接受牛客 BrowserProfileRef。
- 小红书 search/detail 在 Profile、CDP 或 Sidecar 任一缺失时不得运行。
- Crawl4AI 使用外部 CDP、同一登录 context、一个 browser connection 和 arun_many concurrency=2。
- authentication_required interrupt 后同 thread resume，重复 authorized response 零重复写。
- doctor 不读取 Cookie，且不会把 reachable 表述为 authenticated。

## 3. 真实组件 Smoke

3. 小红书：登录 Profile + MediaCrawler REST 完成 search/detail 并生成 Raw Artifact。
