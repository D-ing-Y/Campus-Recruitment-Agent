## 17. 明确禁止

- 不把旧 Mini Runtime success 当完整业务 success。
- 不把 fixture、预填 predicted、布尔 gold 或 schema parse 当真实语义质量。
- 不保留伪 success/no-op 节点来满足拓扑数量。
- 不把搜索页/搜索卡当岗位详情页。
- 不绕过登录、验证码、限流或风险控制。
- 不把 Session、Run artifact 或 checkpoint 当事实源。
- 不让 dispatcher 变成隐藏 Parent Graph。
- 不提交真实个人材料、live raw、Cookie 或 API key。
