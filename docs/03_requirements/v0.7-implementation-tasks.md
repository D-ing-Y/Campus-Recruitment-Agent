## 17. 明确禁止

- 不把计划优先级或 package status 表达为 Offer/面试成功概率。
- 不追求所有 gap 100% 清零。
- 不给不可改变的硬性资格生成虚假学习任务。
- 不把任务完成直接等同能力升级。
- 不从无解释 rejection 推断能力原因。
- 不让单次反馈直接改变 RoleFamilyProfile 聚合结论。
- 不让 LLM 修改 priority、schedule、因果、profile 或 route。
- 不跨域原地覆盖 Candidate/Role/Intent/Comparison snapshot。
- 不引入外部资源搜索、RAG、自动投递、分布式、Multi-Agent 或 Web UI。
