# v0.7.1 WP3.2.1 认证社区浏览器会话

状态：Implemented / Live Partial（WP 保持开启）
日期：2026-08-13

关联 RFC：`docs/04_rfc/0017-authenticated-community-browser-sessions.md`
关联 ADR：`docs/05_adr/0019-use-isolated-real-chrome-profiles-for-community-sources.md`
关联 Contract：`docs/06_contracts/community-retrieval-contract.md`

## 1. 目标

在不绕过登录、验证码、robots 或平台风控的前提下，为牛客和小红书分别维护一个项目专用的真实
Chrome Profile。用户在可见浏览器中正常登录后，Crawl4AI 和 MediaCrawler 只复用该登录态完成有界、
只读的社区详情采集。

```text
Brave credential -> Nowcoder discovery
Nowcoder BrowserProfileRef -> real Chrome/CDP:9223 -> Crawl4AI detail
Xiaohongshu BrowserProfileRef -> real Chrome/CDP:9222 -> MediaCrawler REST search/detail
```

## 2. 功能要求

### FR-01 Profile 隔离与引用

- 牛客与小红书使用独立 Profile、独立 CDP 端口和独立进程；不得共享日常 Chrome Profile。
- Profile 保存在 Git 忽略的 `data/cache/browser_profiles/`，根目录权限为 `0700`。
- Graph、checkpoint、trace、Artifact、receipt 和报告只允许保存 `BrowserProfileRef`，不得保存真实路径、
  Cookie、Storage State、CDP WebSocket 或浏览器命令行。
- `BrowserProfileRef` 只允许
  `local-browser-profile://nowcoder_experience/<name>` 与
  `local-browser-profile://xiaohongshu_experience/<name>`。

### FR-02 CLI 生命周期

- `campus-agent auth browser-profile init|open|status|stop` 是唯一正式管理入口。
- `open` 使用系统真实 Chrome、loopback CDP、固定 Profile 和官方入口页；登录、扫码、短信与验证码由
  用户手动完成。
- `stop` 只允许停止由项目启动且 PID、命令、Profile 与端口均匹配的进程；不得按端口终止未知进程。
- 端口占用、Profile 锁、路径越界、符号链接、Chrome 缺失和 CDP 不可达必须结构化失败。

### FR-03 按操作授权

- `nowcoder_experience.collect` 继续要求 Brave `CredentialRef`；
  `fetch_community_details` 单独要求牛客 `BrowserProfileRef`。
- `xiaohongshu_experience.collect/fetch_detail` 要求小红书 `BrowserProfileRef`、CDP 可达和
  MediaCrawler Sidecar 健康。
- SourceCapabilities 必须按 `collect|fetch_detail` 声明授权要求；旧 `authorization_mode` 保持兼容读取。
- Graph 使用 `pending_auth_requirement` 记录 source、operation 与 mode，并兼容旧
  `pending_auth_source_id` checkpoint。

### FR-04 Crawl4AI 与 MediaCrawler

- Crawl4AI 0.9.2 使用外部 `cdp_url` 和已有登录 context，仍以一次 `arun_many()`、并发 2 抓取详情。
- Crawl4AI 必须保持 `enable_stealth=false`、无代理、无 LLM extraction、无独立无登录 context；关闭时
  只能断开 CDP，不得终止真实 Chrome。
- MediaCrawler 保持仓库外固定 commit、localhost REST、`CDP_CONNECT_EXISTING=True` 和只读
  search/detail；不恢复 MCP，不在主项目管理 Sidecar 进程。
- 仅 Profile/CDP 可达不能证明已登录；真实 search/detail 成功才可写入最近认证验证结果。

### FR-05 Graph、安全与证据

- 会话缺失或失效必须返回 `authentication_required` 并进入可恢复人工授权 interrupt。
- 用户重新登录后使用相同 thread resume；重复 resume 不得重复写 Artifact、Fragment、Cluster 或 receipt。
- raw-before-parse、URL/final URL allowlist、robots、唯一主帖 selector、逐帖抽取、三层去重、LLM 预算和
  每用途 3 个独立内容簇门槛保持不变。
- doctor 只做本地配置、权限、进程、CDP 和 Sidecar health 检查；不得读取 Cookie，也不得把“可达”
  表述为“认证已通过”。

## 3. 非目标

- 不自动填写账号、扫码、短信或验证码。
- 不使用 stealth、代理轮换、验证码服务或其他风险控制绕过。
- 不把 Brave、Crawl4AI 或 MediaCrawler 接成 MCP。
- 不 vendor 或修改 MediaCrawler 源码，不管理其 Uvicorn 进程。
- 不使用日常 Chrome Profile，也不把真实社区正文或登录材料提交到 Git。

## 4. 完成条件

- 文档、契约、代码、离线测试、全量回归和 Eval report 完成。
- Brave、牛客认证详情和小红书 search/detail 三项真实组件 smoke 均成功。
- “美团后端开发”完整 Role Graph 的面经与风评各达到 3 个独立内容簇，accepted Raw/quote trace 均为
  1.0，且零用途串线、零预算超限、零秘密泄漏。
- 任一 live 门禁未通过时保持 Live Partial/Blocked，不得关闭 WP3.2.1。

当前结果：双 Profile、按操作授权、两条真实组件链路和离线回归已经通过；严格 L2 在进入社区搜集前
因招聘前置源未形成“美团后端开发”有效岗位簇而返回 `detail_evidence_missing`。因此本 WP 仍为
Live Partial，不更新 Accepted/Closed 状态，也不以无关职位或 fixture 替代真实前置证据。
