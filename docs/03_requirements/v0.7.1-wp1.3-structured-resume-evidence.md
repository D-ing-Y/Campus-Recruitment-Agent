# v0.7.1 WP1.3 结构化简历证据 Workflow 需求

状态：Implemented / E4 Human Review Pending  
日期：2026-07-31  
前置：WP1、WP1.1、WP1.2、WP2 既有实现

> 本工作包承接讨论阶段暂称的“WP1.2 Resume Evidence Workflow Correction”。仓库中的
> WP1.2 已用于 Candidate 经历分类补丁，因此正式编号顺延为 WP1.3。

## 1. 当前问题

当前 CandidateProfileGraph 在 PDF 提取后立即生成 Candidate Claim、投影画像并评价充分性，导致
“简历忠实转录”和“用户画像分析”共享同一份模型输出协议。Candidate Typed Claim 反向限制了简历
字段，联系方式、个人优势、期望职位、奖项和自定义区块无法形成完整的结构化原始证据；用户也只能在
画像形成后修正，无法先确认 PDF 是否被正确转录。

## 2. 目标流程

系统必须拆成两个有显式 typed handoff 的子 Workflow：

```text
PDF → Artifact/Extraction/Fragment → ResumeDraft → Human Review
    → ResumeEvidenceSnapshot

ResumeEvidenceSnapshot → Candidate Claim → Validator → CandidateProfile
    → Sufficiency → Agent question loop
```

ResumeEvidenceGraph 是确定性、顺序执行、可恢复的证据构建流程；CandidateProfileGraph 才负责画像
凝练、置信度和信息缺口决策。

## 3. 功能要求

### FR-01 BOSS 风格结构

ResumeDraft 按固定顺序保存个人信息、个人优势、期望职位、工作/实习经历、项目经历、教育经历、
专业技能和自定义内容。列表区块逐条保存；纵向科研、横向开发、课设和毕设作为项目经历的原始子类型，
不得提升为顶层区块。

### FR-02 来源定位

每个非空叶子字段必须由应用生成的 canonical JSON Pointer 映射到至少一个 SourceRef。SourceRef 必须
包含 Artifact、Fragment、页码、文本哈希和可选字符范围。模型只能引用当前 PDF 的 Fragment ID，
不能提交任意字段路径。

### FR-03 人工确认

- 简单区块整块确认；列表区块逐条确认并在末尾确认无遗漏；
- 动作为 confirm、correct、remove、retry、cancel，不提供 skip；
- 空区块必须显式成为 confirmed_empty；
- correct 只修正 PDF 转录或补回 PDF 中漏提取内容，不接受 PDF 外的新事实；
- 所有区块确认前不得创建 ResumeEvidenceSnapshot 或 Candidate Claim。

### FR-04 不可变证据快照

ResumeEvidenceSnapshot 只保存用户确认后的结构、来源映射和审核回执引用。它不保存画像置信度，
也不把简历陈述外推为客观已验证事实。后续修改必须产生新版本，不原地覆盖已发布快照。

### FR-05 PDF 与隐私边界

- pypdf 为主解析器，pdfplumber 为质量门禁失败后的回退解析器；
- 本版本只接受带可用文本层的 PDF，不引入 OCR；
- 个人信息在本地提取，模型输入必须脱敏姓名、电话、邮箱、微信等字段；
- Prompt、run artifacts、checkpoint 安全摘要和 Git 不得包含完整简历或未脱敏 PII。

### FR-06 Candidate typed handoff

Candidate build 只接受 confirmed ResumeEvidenceSnapshot ID，并验证 owner、candidate 和状态。旧
`candidate build --input` 直接移除。旧 Artifact、Claim 和 ProfileSnapshot 继续可读；旧 Candidate
checkpoint 恢复必须返回 legacy_session_incompatible。

## 4. 验收门禁

- pre_confirmation_claim_count = 0；
- unconfirmed_field_persisted_count = 0；
- duplicate_review_write_count = 0；
- pii_leak_count = 0；
- 所有简历派生 Claim 都可回溯到 ResumeEvidenceSnapshot 与 PDF Fragment；
- 匿名回归、CLI、跨进程 resume、全量 pytest、compileall 和真实简历 E4 均通过后才能恢复 WP1 Passed。
