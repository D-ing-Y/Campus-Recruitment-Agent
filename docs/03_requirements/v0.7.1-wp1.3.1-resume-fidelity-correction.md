# v0.7.1 WP1.3.1 简历证据忠实度纠错需求

状态：Implementation Complete / Human Review Pending  
日期：2026-07-31

## 1. 问题

真实简历 E4 暴露出五个缺口：默认 pypdf 文本顺序破坏视觉分组；无标签的出生年月和籍贯
未识别；“至今”被当成缺失值；SourceRef 只能指向整页 Fragment；非空列表逐条确认后又要
整体确认。已发布 Snapshot 不可变，必须通过显式 reparse 生成新 Draft 和新版本。

## 2. 需求

1. Resume PDF 优先使用 pypdf layout extraction；质量不通过才回退 pdfplumber。
2. 个人信息区块必须支持常见无标签头部排列，但不得在简历主体中猜测出生信息。
3. 证据层保留“至今”等原始时间语义，不得转为表示缺失的 null。
4. 每个非空叶子字段必须获得字段级 SourceRef span；不得用整页 fallback 伪装精确来源。
5. CLI Source 摘要必须以当前 record/block 的 span 为中心，不再固定显示页首。未来 UI 直接
   展示 PDF 页面，本补丁不实现图形 UI。
6. 非空列表在最后一条记录完成后自动确认区块；空列表仍必须确认 `confirmed_empty`。
7. `resume import --reparse` 必须复用原 PDF Artifact，但创建新 Draft；旧 Draft/Receipt/Snapshot
   保持不变。新 Snapshot 确认前不替换 session 当前引用。
8. `pre_confirmation_claim_count` 按本次 import 前后差值计算；旧 checkpoint 不得让历史 Claim
   被误报为本次新写入。

## 3. 验收

- 真实 PDF 中的出生年月、籍贯被本地正确识别；
- 兰州大学只保存研究方向，山东大学保存核心课程；
- 两条项目、两条教育、两条荣誉、专业技能无遗漏和新增幻觉；
- 字段 SourceRef span 可在原 Fragment 中定位到相关文本；
- 非空列表没有 section-complete 额外中断；
- reparse 不修改旧 Snapshot，可发布 version+1 新 Snapshot；
- 全量回归、真实 DeepSeek Tool Calling 和新 E4 完成后才恢复 Passed。
