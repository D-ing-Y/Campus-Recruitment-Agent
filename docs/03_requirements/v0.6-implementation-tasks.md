## 15. 明确禁止

- 不把 coverage 命名为 Offer 概率、成功率或录取概率。
- 不用单一综合分掩盖资格失败、偏好冲突或 unknown。
- 不把 CandidateProfile 缺少某项能力自动判定为 capability gap。
- 不让 LLM 修改状态、权重、分母、GapType、排序或 Graph route。
- 不因官网未核验/岗位过期直接假装候选人不匹配。
- 不因用户调整偏好修改 Candidate Claim。
- 不在 v0.6 subgraph 内直接写 v0.4/v0.5 的画像存储逻辑。
- 不原地覆盖 snapshot、assessment、comparison 或 decision 历史。
- 不引入学习计划、RAG、分布式存储、Multi-Agent、Web UI 或自动投递。
